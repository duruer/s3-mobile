Earlier static notes: XOR decoder at file offset `0xFE72` is in `FUN_0040fb40`/`FUN_0040fdec`: it reads a value from an HKLM key and a key/seed from an HKCR key (via `FUN_00616900`/`FUN_00618030`/`FUN_00617c40`), then decodes the blob with a rolling key (`key *= 0xFED42531`). GOG's NOP makes it a plain copy.
